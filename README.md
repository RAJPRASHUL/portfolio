# Prashulraj's Portfolio

My portfolio is built with React, TypeScript, and Vite. It showcases my projects, education, experience, skills, and ways to get in touch.

## Live portfolio

Visit my portfolio: [portfolio-sigma-azure-76.vercel.app](https://portfolio-sigma-azure-76.vercel.app/)

## Run locally

Requirements: Node.js and npm.

```powershell
npm install
npm run dev
```

Open the local URL printed by Vite, usually `http://localhost:5173`.

## Build

```powershell
npm run build
npm run preview
```
