# Prashulraj's Portfolio

A personal portfolio built with React, TypeScript, and Vite. It keeps the original neo-brutalist visual style while presenting Prashulraj's projects, education, experience, skills, and contact information.

## Run locally

Requirements: Node.js and npm.

```powershell
npm install
npm run dev
```

Open the local URL printed by Vite, usually `http://localhost:5173`.

## Build

```powershell
npm run build
npm run preview
```

## Updating portfolio content

Portfolio sections live in `src/app/components/`. Update the relevant component to change the hero, biography, education, experience, projects, skills, or contact details. The profile image is `src/profile.png`.
